# formregistest — ระบบแบบสอบถาม (เก็บชื่อ + เบอร์โทร)

ระบบแบบสอบถามแยกหน้าบ้าน/หลังบ้าน พร้อมระบบ login เขียนด้วย **Python มาตรฐาน (stdlib) ล้วน** ไม่ต้องติดตั้ง dependency ใด ๆ

## โครงสร้าง

```
app/
├── server.py            # เซิร์ฟเวอร์ + REST API + ระบบ login
├── public/index.html    # หน้าบ้าน (ฟอร์มแบบสอบถามสำหรับผู้ใช้ทั่วไป)
├── admin/login.html     # หน้า login หลังบ้าน
├── admin/dashboard.html # หน้า admin จัดการข้อมูล
└── data/                # ข้อมูลผู้ตอบ + บัญชี admin (สร้างอัตโนมัติ, ไม่ขึ้น git)
```

## วิธีรัน

```bash
cd app
python3 server.py
```

- หน้าบ้าน (ฟอร์ม): http://localhost:8000/
- หลังบ้าน (admin): http://localhost:8000/admin

## บัญชี admin เริ่มต้น

| | |
|--|--|
| ชื่อผู้ใช้ | `admin` |
| รหัสผ่าน | `admin123` |

> ⚠️ ควรเปลี่ยนรหัสผ่านก่อนใช้งานจริง บัญชีถูกสร้างไว้ที่ `app/data/config.json` (รหัสผ่านเก็บแบบ hash ด้วย PBKDF2)

## ความสามารถ

**หน้าบ้าน**
- ฟอร์มกรอกชื่อ-นามสกุล + เบอร์โทรศัพท์ พร้อมตรวจสอบความถูกต้อง (เบอร์ไทย 9–10 หลัก)

**หลังบ้าน (ต้อง login)**
- การ์ดสรุปจำนวนผู้ตอบทั้งหมด/วันนี้
- ตารางข้อมูล ค้นหา ลบรายการ
- ดาวน์โหลด CSV (รองรับภาษาไทยใน Excel)
- ระบบ session-cookie auth

## หมายเหตุ

ข้อมูลผู้ตอบ (`app/data/`) มีข้อมูลส่วนบุคคล จึงไม่ถูกอัปโหลดขึ้น repo (กำหนดไว้ใน `.gitignore`)
